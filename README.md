# Tally releases

Signed Android builds of Tally, a free way to split costs with anyone
(no sign-up, no limits, any currency). Installed copies update themselves
from here. In a browser: https://tally.matisseduffield.workers.dev

**[Download Tally 1.8.3](https://raw.githubusercontent.com/matisseduffield/tally-releases/main/Tally.apk)**

On your phone: open the link, then open the downloaded file and allow
the install when Android asks. You only do this once; after that the app
offers updates itself.

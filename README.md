# Tally releases

Signed Android builds of Tally, a free way to split costs with anyone
(no sign-up, no limits, any currency). Installed copies update themselves
from here. In a browser: https://tally.matisseduffield.workers.dev

**[Download Tally 1.5.9](https://raw.githubusercontent.com/matisseduffield/tally-releases/main/Tally.apk)**

On your phone: open the link, then open the downloaded file and allow
the install when Android asks. You only do this once; after that the app
offers updates itself.

## What's new in 1.5.9

- Amounts in rupiah, yen and other currencies without cents read 150.000 as 150,000, like the receipt
- An expense too small to show in the group's currency can't be saved
- The keyboard's Done key just closes the keyboard, so you can still change the split
- Splitting 33.33% three ways now works
- Split fields no longer reset while you type if rates arrive
